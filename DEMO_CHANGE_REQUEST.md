# Demo Change Request

## Business requirement
The Student Results API should tell the consumer whether a student has passed or failed.

## Acceptance criteria
- Total marks >= 40 -> `PASS`
- Total marks < 40 -> `FAIL`
- Existing student and total fields must continue to work.
- Automated tests must cover PASS and FAIL.

## SCM evidence to demonstrate
1. Existing baseline on `main`
2. Feature branch
3. Configuration/code change
4. Test change
5. Commit history
6. Pull Request
7. CI validation
8. Review
9. Merge
10. Updated controlled state on `main`
